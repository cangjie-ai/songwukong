# 颂 · 悟空（Song Wukong）

一款致敬《黑神话：悟空》的 **2D 横版动作游戏**，可在浏览器中直接运行，也可以双击 `index.html` 本地离线游玩。**零依赖、零构建、无需任何素材文件**——所有画面均由 Canvas 程序化绘制。

## 快速开始

```bash
# 方式一：直接双击 index.html（无需任何环境）

# 方式二：本地起个静态服务器（推荐）
python3 -m http.server 8000
# 或
npx serve .
# 然后浏览器打开 http://localhost:8000
```

调试参数：`index.html?start=1` 跳过标题直接进第一关；`?level=2&start=1` 直接进 Boss 战。

## 操作

| 按键 | 动作 |
|---|---|
| A / D（或 ←/→） | 移动 |
| Space / W | 跳跃 |
| **J** | 轻棍（三连段，命中攒**棍势**） |
| **K** | 重棍（消耗全部棍势，伤害与范围随棍势暴涨） |
| **L** / Shift | 翻滚（全程无敌帧） |
| **U** | 定身术（范围定身 3 秒，Boss 减半，冷却 12 秒） |
| **H** | 喝葫芦回血（50 点，共 3 口，土地庙补满） |
| R | 死亡后于土地庙复活 |

## 关卡设计（当前 2 关）

### 第一回 · 黑风山「苍狼林」
月夜松林横版清怪关，全长 4200 像素：
- **狼卒**（近战，巡逻→索敌→前摇挥刀，可被打出硬直）与**狼弓手**（拉开距离放箭，箭带抛物线）混编，配合高台地形形成火力交叉；
- 中段设**土地庙**：参拜后满血、补满葫芦，并成为死亡复活点（还原原作检查点设计）；
- 关底穿过「禅院山门」进入第二回。

### 第二回 · 观音禅院「火场」
火烧禅院 Boss 战——**苍狼精 · 广智**（600 血，双阶段）：
- 一阶段：三连挥砍（步步进逼）、远距突进斩、飞扑震地（落点 AoE）；
- 二阶段（半血觉醒，怒吼+全屏火星）：动作提速，突进与震地会在地面留下**火焰灼烧区**，逼迫玩家不停走位；
- 蓄力重棍（≥1 段棍势）可打断 Boss 削韧；定身术对 Boss 只有 1.3 秒。

### 还原的核心机制
| 原作机制 | 本作实现 |
|---|---|
| 棍势（Focus） | 轻棍命中攒充能，满 100 得 1 段（上限 3 段），重棍一次性倾泻 |
| 完美闪避/翻滚 | 翻滚全程无敌帧 |
| 定身术 | U 键范围定身，敌人结冰高亮 |
| 酒葫芦 | H 键回血，土地庙补满 |
| 土地庙 | 检查点：回满状态 + 复活点 |

## 技术选型分析

### 为什么当前版本用「原生 JavaScript + HTML5 Canvas」？

目标是**浏览器 / 电脑本地都能跑、先跑起来**，因此第一版选择零依赖方案：

- 打开即玩：无 Node、无构建、无资源加载，`file://` 协议直接运行；
- 部署为静态文件即可上线（GitHub Pages / 任意静态托管）；
- 全部逻辑自己写（游戏循环、AABB 物理、状态机 AI、粒子），最适合理解动作游戏底层原理。

### 技术栈横向对比

| 方案 | 语言 | 优势 | 劣势 | 适合阶段 |
|---|---|---|---|---|
| **原生 Canvas**（当前） | JS | 零依赖、启动最快、可控性 100% | 引擎功能全靠手写 | 原型 / 学习 |
| **Phaser 3 + TypeScript + Vite** | TS | 专业 2D 引擎：精灵动画、瓦片地图(Tiled)、物理、音频、场景管理，生态成熟 | 需要构建工具链 | 正式开发（**推荐主线**） |
| Godot 4 | GDScript/C# | 完整编辑器、动画树、可导出 Web+桌面 | 引入完整引擎学习成本 | 团队/大体量内容 |
| Unity 2D | C# | 工业级工具链 | Web 导出体积大、对 2D 像素游戏偏重 | 商业化大项目 |

### 建议的升级路线

1. **v0（当前）**：原生 Canvas 原型，打磨手感（连段/无敌帧/受击反馈/镜头震动）；
2. **v1**：迁移到 **TypeScript + Vite + Phaser 3**——手感参数可直接平移，换来精灵表动画（美术素材接入）、Tiled 瓦片地图编辑关卡、WebAudio 音乐音效管理；
3. **v2**：桌面端用 **Electron 或 Tauri** 打包成 exe/dmg；加手柄支持（Gamepad API）、存档（localStorage → 云存档）。

## 代码结构

```
index.html      入口（1280×720 画布，自适应缩放）
js/utils.js     数学工具 / AABB / 粒子 / 伤害飘字 / WebAudio 合成音效 / 平台物理
js/input.js     键盘输入（按下沿检测）
js/player.js    天命人：移动跳跃、轻棍三连、棍势重棍、翻滚、定身、葫芦、受击/死亡
js/enemies.js   狼卒 / 狼弓手 / Boss 广智（双阶段状态机）/ 箭矢 / 火焰灼烧区
js/levels.js    两关关卡数据 + 程序化背景（夜林视差 / 火烧禅院）+ 土地庙 / 山门
js/game.js      主循环、镜头（跟随+震动+顿帧）、HUD、关卡流转、标题/死亡/胜利画面
```
